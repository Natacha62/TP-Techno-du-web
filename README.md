# TP Technologie du Web

## Description
Ce projet est un TP de manipulation du DOM avec JavaScript.  
Il comprend deux pages HTML (`convertisseur.html` et `google.html`), des fichiers CSS pour le style (`style.css` et `style2.css`), des fichiers JavaScript (`convertisseur.js` et `google.js`) et des images utilisées dans le projet.  
L’objectif est de pratiquer la manipulation des inputs, radios, checkboxes, barres de volume et barres de progression.
